## 2024-05-07 - [Make interactive list items accessible buttons]
**Learning:** In the NotificationCenter component, using standard generic `<div>` tags with `onClick` event handlers makes the item visually distinct via mouse-based hover (`onMouseEnter`/`onMouseLeave`) but fundamentally inaccessible to screen reader and keyboard navigation tools.
**Action:** Always refactor generic non-semantic interactive tags (`<div onClick="...">`) inside list items to semantic `<button>` elements. Ensure CSS resets (`width: '100%'`, `textAlign: 'left'`, `background: 'none'`, `border: 'none'`) are applied to preserve design continuity. Furthermore, mirror the `onMouseEnter`/`onMouseLeave` state updates to `onFocus`/`onBlur` so that keyboard focus visually behaves the same way as mouse interaction.
