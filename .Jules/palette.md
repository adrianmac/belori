## 2024-05-12 - Standardized Button Loading States with Accessibility
**Learning:** Hard-coding visual changes for button loading text (e.g., "Saving..." instead of "Save") misses critical semantic accessibility markers like `aria-busy` and explicit `disabled` states. Using a dedicated `loading={true}` prop on a UI component abstraction (`PrimaryBtn`, `GhostBtn`) enforces consistency by rendering an inline visual spinner, maintaining the original label length for styling consistency, and adding standard `aria-busy={true}` along with locking interaction state.
**Action:** Always prefer updating base UI components with a `loading` prop that adds `aria-busy` instead of manually switching text. Apply inline SVG spinners alongside the button's static label to make UI interactions clearer and accessible for screen readers.
