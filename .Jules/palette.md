## 2024-06-05 - Accessibility on interactive list items
**Learning:** Found several list items acting as buttons in menus and lists that are implemented as `<div>` elements instead of semantic `<button>` elements (e.g., alerts in NotificationCenter).
**Action:** When creating or modifying interactive list items, use semantic `<button>` elements. Apply inline CSS resets (`background: 'transparent'`, `border: 'none'`, `width: '100%'`, `textAlign: 'left'`) to preserve visual styling. Add `onFocus` and `onBlur` handlers to match existing hover transitions to ensure keyboard navigation has visible indicators, ensuring `onMouseLeave` checks `if (document.activeElement !== e.currentTarget)` before reverting styles. Watch out for CSS shorthand conflicts (like `border: 'none'` overwriting `borderBottom`).
