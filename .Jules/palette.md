## 2026-07-08 - Enhanced FAB keyboard accessibility\n**Learning:** When managing floating action buttons (FABs) with visually hidden action items, screen readers and keyboard navigation require explicit state management. Elements hidden via CSS / remain in the DOM and can steal focus.\n**Action:** Always add `tabIndex={isOpen ? 0 : -1}` to prevent actionable items from receiving focus when closed, apply `aria-hidden={!isOpen}` to the container, and use `aria-controls`/`aria-haspopup` on the main toggle button.
