## 2024-06-25 - Prevent Focus on Hidden FAB Menu
**Learning:** For a custom FAB menu, setting `opacity: 0` or using `transform` to visually hide menu items leaves them focusable by keyboard, leading to a confusing screen reader and keyboard navigation experience. Similarly, the main trigger button needs `aria-expanded`, `aria-controls`, and `aria-haspopup` correctly setup to inform screen reader users of the hidden menu items.
**Action:** Always apply `aria-hidden={!isOpen}` to the action menu container and ensure focusability on child interactive elements is correctly toggled via `tabIndex={isOpen ? 0 : -1}` to ensure hidden elements do not receive keyboard focus. Additionally, ensure the FAB toggle button has `aria-controls`, `aria-haspopup`, and `aria-expanded` and that focus animations trigger via `onFocus` & `onBlur`.
