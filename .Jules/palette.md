## 2024-07-10 - Sidebar focus indicators and duplicated prop bug
**Learning:** Adding keyboard focus indicators (`onFocus`/`onBlur`) that mimic inline hover styles (`onMouseEnter`/`onMouseLeave`) improves accessibility without needing custom CSS. It is critical to add checks like `document.activeElement !== e.currentTarget` in `onMouseLeave` to prevent keyboard focus states from clearing when a mouse cursor coincidentally leaves the focused element. Also, be wary of React's prop overriding—declaring `onMouseEnter` twice on the same element overrides previous declarations.
**Action:** When converting non-semantic UI to semantic `<button>`s, always pair `onMouseEnter` with `onFocus` and `onMouseLeave` with `onBlur` applying these retention checks, and double-check for duplicated inline event handlers that can cause bugs.
